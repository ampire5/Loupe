# Loupe

## Language

### Lightweight playback

A mode in Loupe for playing, pausing, seeking and stepping through videos and animated images one frame at a time, with low resource use while browsing a folder. Opening the current video in the standalone FrameScrub app starts it paused at the position shown in Loupe.

### Scrub Lock

A temporary input mode for the current video or animation. It activates FrameScrub's playback gestures and transport shortcuts while the viewer stays in Loupe. Shift-Control toggles the mode and Escape exits it.

## Home sources

**Web Images**

A Home source for finding images on the web by text query and opening a selected result in Loupe’s viewer.
