# Idle CPU: Loupe and WindowServer at rest (2026-10-23)

`scripts/idle-cpu.sh FOLDER [IMAGE]` — CPU time delta (cumulative `ps -o time=`) over a 60 s window after a 60 s
settle, as % of one core. The owner's Loupe state is backed up and restored around the run; settings come from an
empty `LOUPE_CONFIG_DIR` (defaults, no session restore).

Machine: iMac20,1, Intel Core i7-10700K, 8 cores (16 threads), macOS 26.7.1. Build: L20 (thumbs-ahead-lts 4eb98da).
Folder: local SSD, 2 HEIC images.

| State | Loupe | WindowServer |
|---|---|---|
| WindowServer baseline (no Loupe) | – | 58.6 |
| Home on the folder | 0.7 | 66.6 |
| Viewer on an image | 1.2 | 61.2 |
| Window hidden | skipped | skipped |

- Loupe stays under the ~1–2 % threshold in both states.
- WindowServer's baseline was high (the machine was in use during the run), so its +8 / +2.6 points with Loupe are
  within noise; repeat on an otherwise idle machine before reading anything into them.
- Hiding the app through `NSRunningApplication.hide()` did not take effect without extra permissions; that state was
  skipped.
- Still to measure: a large folder on an SMB share (the shell running the script needs access to network volumes).
