# Keys and Gestures and Key Bindings

Measurements on Apple Silicon, macOS 27.2.1, debug build. Times are main-thread CPU in milliseconds.

| Action | First visit | Later visits |
| --- | ---: | ---: |
| Settings → Key Bindings, starting on Mouse & Trackpad | 64 | 8–9 |
| Open help in a 340 × 260 AppKit window, first help use in the process | 73.7 | 0.5–0.8 |
| Open help in a new 1200 × 700 AppKit window in the same process | 10.3 | 0.6–0.9 |

Settings used the real window via `LoupeBench settings --start mouse --rounds 3 --settle 180 --icons 0`.
Key Bindings' longest uninterrupted block was 40 ms on its first visit and 9 ms on return. Round totals
across all pages visited were 403, 84 and 78 ms.

The help measurements used the production AppKit view mounted in a separate test window with a neutral
22-row fixture. They cover showing the view and synchronously laying it out, including the first focus
change. They exclude the viewer and Metal rendering. The layout and responder tests use Loupe's
effective bindings, including a changed `input.conf`, and check compact, wide and resized windows.

Intel performance and assistive-technology walkthroughs remain unmeasured.

The dark HUD backdrop was checked against a bright multicolour background and the same AppKit fixture.
With the HUD material and dark veil, opening the compact view took 70.3 ms for the first use and 0.3–0.7 ms on
return. The wide view took 6.3 ms on its first use in that process and 0.3–0.5 ms on return.
