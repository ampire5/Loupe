# Feedback while viewing

Approved direction: feedback is optional and part of normal viewing. Option-1 confirms a comfortable inspection viewport; Option-2 confirms an overview composition. Shift advances after persistence. Either intent can exist alone. Existing references keep their geometry and meaning; no migration infers object relevance from visibility.

Use the existing reference store and viewer commands rather than a mandatory annotation screen. Add independent per-object feedback (inspect, avoid as centre, blurred, detector mistake), tied to source revision, detector evidence, frozen boxes and intent. A context menu must coexist with right-drag zoom. Overlapping detections must be explicitly distinguishable. Store only explicit feedback; gestures and silence are not labels.

Expose confirmations, object menu, comparison and undo as assignable input actions. Undo restores only the last successful transaction and rejects intervening edits from other windows. Comparison is opt-in and uses the existing learning comparison window, preserving its validation and fitting safeguards; it must never manufacture a preferred answer or silently fit while browsing.

The new object feedback is collected separately from crop targets for later training. Do not change the optimizer to treat blur or excluded centres as global category penalties. Explain this limitation in user documentation. No private models, labels or image paths enter this repository.
