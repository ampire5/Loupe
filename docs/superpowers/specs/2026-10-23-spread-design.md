# Разворот: две фотографии на экране (`D`) — дизайн

Дата: 2026-10-23. Запрос пользователя: «на кнопку D режим с двумя страницами на экране, возможно с подопциями —
продумать, как сделать лучше, идеально». Решения ниже — мои (пользователь попросил решать самому); проверка — на сборке.

## Цель

Смотреть снимки парами, как разворот книги или журнала: сканы страниц, комиксы, пары портретных фото, сравнение
соседних кадров. Включается одной клавишей, запоминается для папки, ведёт себя как обычный просмотр — зум, панорама,
лента, кэш, статус-бар работают с парой.

## Поведение

- **`D`** — разворот вкл / выкл для папки (ключ папки, как `L`); **`⇧D`** — сохранить как значение по умолчанию в
  `loupe.conf` (как `⇧L`). Тост: «Two pages» / «One page» (и «Two pages · saved as default»).
- **`⌥D`** — сдвиг пары на одну страницу (обложка отдельно ↔ без обложки). Нужен, когда пары «съехали»: страница 1 —
  обложка, развороты 2–3, 4–5… Флаг папки.
- **Пары.** Страницы считаются от начала папки: без сдвига — (1,2), (3,4)…; со сдвигом — (1), (2,3), (4,5)…
  Последняя нечётная — одна.
- **Альбомные снимки — по одному** (по умолчанию). Снимок, у которого ширина больше высоты (с учётом ориентации
  EXIF), показывается один; пары дальше считаются с него заново. Так серия «портрет, портрет, пейзаж, портрет,
  портрет» даёт (1,2), (3), (4,5). Ключ `spread-landscape = alone | pair`.
- **Порядок** — слева направо; ключ папки `spread-direction = ltr | rtl` (манга: первая страница справа). В меню View.
- **Узкое окно.** Если вид уже, чем выше (соотношение < 1.0), разворот временно показывает одну страницу (ту, что
  была левой по порядку чтения), флаг папки не меняется; расширили окно — снова пара. Так разворот не ломает работу на
  вертикальном мониторе.
- **Раскладка пары.** Обе страницы приводятся к одной высоте и стоят вплотную (без зазора, как книга); пара —
  «виртуальный снимок» шириной w₁·h/h₁ + w₂·h/h₂ и высотой h. Вписывание, «1:1», свободный зум, панорама, пружина и
  замок вида работают с этим виртуальным снимком как с одним (те же `ViewTransform` и `ZoomMode`). «1:1» — по
  странице с большим разрешением.
- **Листание.** `→` / `←`, колесо, жесты — на одну пару (или одиночную страницу). `Home` / `End` — первая / последняя
  пара. `⌥←→` (соседняя папка) — открывает её в её собственном режиме.
- **Положение** — номер первой страницы пары. Статус-бар и заголовок: «12–13 / 380»; лента подсвечивает обе ячейки и
  центрируется между ними; скраб ленты попадает на пару, содержащую ячейку. Info-панель — о странице под указателем
  (по умолчанию — первой по порядку чтения).
- **Цвет.** Автоцвет, вибрация, фильтры масштабирования — для каждой страницы свои (своя LUT), как при одиночном
  просмотре.
- **Кэш.** Обе страницы пары — «текущие»: обе получают полное разрешение после задержки; соседи — следующая и
  предыдущая пара.

## Ключи

| Ключ | Значения | По умолчанию | Папка |
|---|---|---|---|
| `spread` | `yes` / `no` | `no` | да |
| `spread-shift` | `yes` / `no` | `no` | да |
| `spread-direction` | `ltr` / `rtl` | `ltr` | да |
| `spread-landscape` | `alone` / `pair` | `alone` | да |

Settings › Interface (или новая секция «Two pages»): все четыре, с описаниями. Меню View: «Two Pages» (D),
«Shift Pages» (⌥D), «Right to Left».

## Архитектура

- **LoupeCore (чистые типы, тесты):**
  - `SpreadPlan` — по списку размеров страниц (с ориентацией), флагам `shift` / `landscape` и индексу даёт пару
    `(first: Int, second: Int?)`, следующую / предыдущую пару, пару, содержащую индекс, первую / последнюю.
  - `SpreadLayout` — по двум размерам и направлению: виртуальный размер и прямоугольник каждой страницы внутри него
    (в долях), чтобы рендерер и указатель (Info-панель) пользовались одной геометрией.
  - `Config`: четыре ключа, ключи папки; `KeyMap`: `toggleSpread` (d), `saveSpread` (⇧d), `shiftSpread` (⌥d).
  - `CacheFocus.companion: Int?` и план кэша: компаньон сразу после текущего, шаг соседей — по парам.
  - `StatsLine` / `WindowTitle`: диапазон «12–13 / 380».
- **LoupeRender / RenderLoop:** `Snapshot` получает до двух страниц `(image, orientation, color, rect)`;
  `TileRenderer.encode` — с прямоугольником вывода (viewport) и без очистки для второй страницы. Одна вьюха, один
  `CAMetalLayer`, один display link — кадры двух страниц всегда синхронны.
- **ViewerSession:** вторая запись (`companion`), шаг по `SpreadPlan`, обе страницы в `setFocus`, получение кадров
  для обеих; виртуальный размер — в `ViewTransform`.
- **Лента, статус-бар, заголовок, Info** — по пунктам «Положение».

## Сборка и проверки

Сборка **L7** (LTS-вариант на этом Intel). Ручные проверки: пары, обложка (`⌥D`), альбомные по одному, `rtl`,
узкое окно, зум / панорама / замок вида на паре, листание по парам и последняя одиночная, лента и статус-бар,
автоцвет у каждой страницы, переход в соседнюю папку и обратно (флаг папки), скорость листания пар (кэш).

## Вне этого документа

Двойные страницы в архивах с разной высотой как одна «широкая» страница (определение разворота по ширине — позже,
если понадобится); три и более страниц; синхронный зум «сравнение двух снимков» с независимыми панорамами.
