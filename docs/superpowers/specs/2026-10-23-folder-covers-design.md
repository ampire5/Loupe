# Обложки папок и архивов в Home: всегда с фото — дизайн

Дата: 2026-10-23. Запрос пользователя: для видимой части сетки как можно быстрее кэшировать по несколько фото из
каждой подпапки и архива, чтобы не было пустых карточек; продумать раскладку превью на карточке папки — несколько
вариантов, выбрать оптимальный и красивый. Решения — мои; выбор раскладки по умолчанию проверяется на сборке.

## Как сейчас

Карточка папки или архива показывает мозаику до 4 фото (`HomeMosaic`), но собирает её только из каталога эскизов:
`folderSamples` возвращает файлы, у которых эскиз уже есть. Папка или zip, которые ни разу не открывали, остаются с
символом. Генерация для неоткрытого есть только у одиночной обложки (`cover`, Recent / Sessions).

## Цель и успех

- Видимые карточки папок и архивов получают фото без открытия папки: первые — за доли секунды на SSD, остальные —
  по мере прокрутки; после первого раза — мгновенно из каталога.
- Папка без своих фото, но с подпапками, показывает фото подпапок; символ остаётся только у действительно пустых.
- Компьютер не нагружается: фон уступает просмотру, параллелизм ограничен, ничего тяжёлого на главном потоке.

## Отбор фото

- **Папка:** листинг только имён (`BrowserListingSource.names`, без stat), фото по сортировке имён; берётся 4
  равномерно по списку (первое, ⅓, ⅔, последнее) — разнообразнее, чем первые четыре подряд. Последний открытый снимок
  папки (если есть) — первым, как сейчас.
- **Архив zip:** одно чтение центрального каталога (`ArchiveReader`), тот же выбор по именам записей.
- **Папка без фото:** первые 4 подпапки по сортировке, у каждой — её обложка (рекурсивно, глубина ≤ 2; результаты
  подпапок тоже идут в каталог). Ни фото, ни подпапок с фото — «пусто», запоминается на сессию, символ.
- **Галереи Stash** (веб-страница) — вне этого документа.

## Порядок и пределы

- Источник уже получает id в порядке «видимые, потом запас» (`wantImages`). Кит добавляет число видимых:
  `wantImages(_ ids: [String], visible: Int, width: CGFloat)` с реализацией по умолчанию через старый метод.
  Видимые — сразу; запас — после остановки прокрутки на 150 мс.
- Новая очередь обложек в `ThumbnailStore` (`CoverQueue`): одновременно листингов ≤ 2 на локальном томе, 1 на сетевом;
  генерация эскизов — через существующий пул декодирования эскизов (`.utility`), не больше 4 эскизов на папку;
  отмена задач, чьи карточки ушли из живой зоны. Видимые эскизы файлов (`ThumbnailQueue`) идут раньше обложек; при
  листании в просмотрщике очередь обложек ставится на паузу.
- Листинг с ограничением времени (2 с на сетевом томе): что успели — из того и выбираем.
- Результат — в каталог (`db.put`, как у `cover`), поэтому `folderSamples` в следующий раз найдёт их сразу.
- Числа пределов подбираются бенчем `ThumbsBench` (локальная папка с подпапками JPEG на SSD), замер — рядом с
  константой.

## Раскладки обложки (`folder-cover`)

Кит: `HomeMosaic.Layout` и ключ Loupe `folder-cover`:

| Значение | Вид |
|---|---|
| `grid` | 2 × 2 (как сейчас при 4 фото) |
| `hero` | одно большое сверху (⅔ высоты), три маленьких снизу |
| `stack` | стопка из трёх отпечатков с лёгким поворотом (±4°) и тенью — как стопка фото на столе |
| `single` | одно фото во всю карточку |

- **Адаптивно:** при ширине карточки < 110 pt любая раскладка становится `single` (мелкие ячейки не читаются).
- **По умолчанию — `hero`:** главное фото узнаётся, три снизу говорят «внутри ещё». Альтернативы — в Settings ›
  Home (выбор из четырёх) и в меню «Вид». Если фото меньше, чем ячеек: `hero` с 2–3 фото — большое и 1–2 малых,
  с 1 — `single`.
- Архив — та же раскладка плюс маленький бейдж `zip` в углу (как сейчас символ).

## Тесты

- Отбор: равномерные 4 по списку, последний открытый — первым, папка без фото → подпапки, пустая → nil.
- Очередь: пределы одновременности (локальный / сетевой), видимые раньше запаса, отмена ушедших.
- Раскладки: прямоугольники ячеек для каждого вида и числа фото; адаптивный `single`.
- Ключ `folder-cover` в Config.

## Сборка

**L8** (LTS-вариант). Ручные проверки: большая папка с неоткрытыми подпапками — карточки заполняются по мере
прокрутки, без рывков; zip; папка-контейнер; пустая; сетевой том; четыре раскладки и адаптивный режим; повторный
вход — мгновенно.
