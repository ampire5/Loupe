# Разворот (`D`) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** клавиша `D` показывает снимки парами (разворот), с флагами папки «сдвиг», «справа налево», «альбомные по одному»; зум, листание, кэш, лента и статус-бар работают с парой.

**Architecture:** вся логика пар и геометрии — чистые типы в LoupeCore (`SpreadPlan`, `SpreadLayout`); рендерер рисует до двух страниц в один кадр одного `CAMetalLayer`; сессия держит вторую запись и шагает по плану; пара для `ViewTransform` — один виртуальный снимок.

**Tech Stack:** Swift 6.2, AppKit, Metal, Swift Testing; Loupe собирается только своими скриптами (`scripts/test.sh`, `scripts/make-app.sh`).

**Spec:** `docs/superpowers/specs/2026-10-23-spread-design.md`

## Global Constraints

- Ключи и значения ровно из спецификации: `spread yes|no` (по умолчанию `no`), `spread-shift yes|no` (`no`), `spread-direction ltr|rtl` (`ltr`), `spread-landscape alone|pair` (`alone`); все четыре — ключи папки.
- Клавиши: `d` — `toggleSpread`, `⇧d` — `saveSpread`, `⌥d` — `shiftSpread`. Тосты: `Two pages`, `One page`, `Two pages · saved as default`, `One page · saved as default`, `Pages shifted`, `Pages not shifted`.
- Пара: обе страницы одной высоты, вплотную, без зазора; «альбомная» — ширина > высоты после ориентации EXIF; окно с соотношением < 1.0 показывает одну страницу (первую по порядку чтения), флаг не меняя.
- Положение — индекс первой страницы пары; текст статус-бара «12–13 / 380» (en dash).
- LoupeCore не импортирует AppKit; главный поток не блокируется; фон уступает просмотру.
- Проекты публичные: никаких личных путей и имён папок в коде, тестах, коммитах.
- Коммиты — с трейлерами из инструкции исполнителю.

## Review Focus

1. Папка из одного снимка и папка, где все снимки альбомные, в режиме разворота — один снимок, листание по одному, без падений — тест `singlePageFolders` (Task 1).
2. Включение `D` на середине папки: пара строится вокруг текущего снимка (пара, *содержащая* текущий), а не прыгает к началу — тест `pairContainingIndex` (Task 1).
3. Смена флага папки (`D`, `⌥D`) и переход в соседнюю папку со своим флагом: кэш не держит полное разрешение лишней страницы — тест `companionFocusFollowsPlan` (Task 3).
4. Повёрнутая EXIF-страница (ориентация 6/8) считается по видимым размерам — тест `orientationDecidesLandscape` (Task 1).
5. Узкое окно ↔ широкое на лету — ручная проверка L7 (Task 6) + тест `narrowViewShowsOnePage` (Task 2).

**Interfaces:**
- Produces:

  - `public struct SpreadPair: Equatable, Sendable { public let first: Int; public let second: Int?; public var pages: [Int] }` (`pages` — в порядке листания; порядок на экране решает `SpreadLayout`).
